# Return To Wearer

The wearer should not need to understand the import bridge.

## Output Shape

One sentence:

```text
Disease Scout: possible disease or stress signal. Confidence medium. Next check: capture the underside and a healthy comparison leaf.
```

## Ordinary Ray-Ban Meta

Use:

- phone audio routed to glasses speakers;
- phone notification/message announced or read by glasses.

Do not claim:

- custom in-lens UI;
- overlays;
- display cards.

## Meta Ray-Ban Display

Use:

- hosted HTTPS Web App;
- compact result card;
- only after MRBD hardware test.

## Supervisor Output

The full packet stays in the app/dashboard:

- image;
- possible disease;
- confidence;
- evidence quality;
- next check;
- supervisor action;
- JSON.

This keeps the wearer flow short and the judge proof inspectable.
